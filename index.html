Live mode sends one email to the same model and runs the same checks. It's limited to 5 tries a day per person, and it stops for everyone when the day's free allowance is used.

Live mode sends the text you paste to a small program on Cloudflare, which passes it to a Workers AI model and returns the result. That program doesn't store or log your text. It keeps only a daily count of requests, tied to a scrambled version of your IP address and deleted within 24 hours. Cloudflare says it doesn't use Workers AI inputs to train models.
